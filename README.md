# DL learning
下面列出深度学习常见的几种模型以及其相关知识点：

### 1. 卷积神经网络(Convolutional Neural Network, CNN)
 - 中文: 卷积神经网络
 - 英文: Convolutional Neural Network (CNN)
 - 知识点: 卷积、池化、卷积神经网络的结构等

### 2. 循环神经网络(Recurrent Neural Network, RNN)
 - 中文: 循环神经网络
 - 英文: Recurrent Neural Network (RNN)
 - 知识点: 反向传播算法、LSTM、GRU、循环神经网络的结构等

### 3. 自编码器(Autoencoder, AE)
 - 中文: 自编码器
 - 英文: Autoencoder (AE)
 - 知识点: 神经网络的基本知识、反向传播算法、编码器与解码器的结构及特点等

### 4. 生成对抗网络(Generative Adversarial Networks, GAN)
 - 中文: 生成对抗网络
 - 英文: Generative Adversarial Networks (GAN)
 - 知识点: 博弈论、生成模型、判别模型、GAN的结构和训练方法等

### 5. 注意力机制(Attention Mechanism)
 - 中文: 注意力机制
 - 英文: Attention Mechanism
 - 知识点: 神经网络的基本知识、多头注意力机制、自注意力机制、注意力机制在不同领域的应用等

### 6. 深度强化学习(Deep Reinforcement Learning, DRL)
 - 中文: 深度强化学习
 - 英文: Deep Reinforcement Learning (DRL)
 - 知识点: 强化学习基础知识、神经网络与强化学习的结合、Q-learning、Actor-Critic等

以上仅是深度学习中较为常见的几种模型，以及相应的知识点。实际上深度学习领域较为广泛，还有许多其他模型和技术，如卷积自编码器(CAE)、变分自编码器(VAE)、对抗自编码器(AAE)、半监督学习、迁移学习等等。
